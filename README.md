# Fantasy Currency Converter

A polished SwiftUI currency converter with a fantasy-inspired interface, reusable components, exchange information, and automated iOS workflow files.

![Swift](https://img.shields.io/badge/Swift-F05138?logo=swift&logoColor=white)
![SwiftUI](https://img.shields.io/badge/SwiftUI-0D96F6?logo=swift&logoColor=white)
![CI](https://img.shields.io/badge/GitHub_Actions-2088FF?logo=githubactions&logoColor=white)

## Features

- Interactive currency selection
- Two-way conversion flow
- Reusable currency icons and grid components
- Exchange-rate information screen
- Custom visual assets and app icon
- Unit and UI test targets
- GitHub Actions configuration

## Run

1. Clone the repository.
2. Open `ConverterApp.xcodeproj` in Xcode.
3. Select an iOS simulator.
4. Build and run with `⌘R`.
